# IPL Win Predictor

A machine learning-based IPL Win Predictor that estimates the winning probability of teams during an IPL match based on match conditions.

## Features

- Predicts match-winning probabilities
- Uses historical IPL data
- Data preprocessing and feature engineering
- Simple and user-friendly interface
- Real-time prediction support

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit (if used)

## Project Structure

```
├── ipl_win_predictor.py
├── datasets/
├── models/
├── requirements.txt
└── README.md
```

## Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/ipl-win-predictor.git
```

2. Navigate to the project folder

```bash
cd ipl-win-predictor
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python ipl_win_predictor.py
```
